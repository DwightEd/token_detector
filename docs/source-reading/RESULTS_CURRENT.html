全数据集方法对照：截至恢复记录 2026-10-31

V3 / witness 是仍保留的金融研究候选；它不是所有数据集、所有观察模型上的最优方法。 时间上更晚的候选已试验，但没有建立稳定替代证据。当前公开 API 的默认值仍为 V1 / shared；R4 是历史任务配方。研究讲解以 V3 方法为主。

单元格为 AUROC / AP，越大越好；AP 是 average precision。这里只整理已有结果，没有新运行、重算指标或据标签挑选新方法。— 表示该运行体系中未恢复到结果，不能跨观察模型补数。 历史任务已被查看，只能作为探索证据。金融是 silver 编辑标签；HalluRAG 是句标签投影；它们不能等同人类自然 token 错误标注。 这些现成标注可以直接用于评价；标签来源与历史开发暴露只是解释其证据范围，不是禁止使用。按用户指定，HalluRAG包含答案的891答为与RAGTruth对照的主组；全部及不含答案组继续单列。R4/V3主表、错例与0.8目标。
