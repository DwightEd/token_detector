# 初始方案：把区域借用与局部分辨能力拆开验证

## 不变的问题锚点

**底层问题**：给定提示、来源和已经生成的回答，在保留原始 token/字符位置的前提下，定位回答中不受来源支持的内容，并说明分数的统计含义。

**必须解决的瓶颈**：当前来源删除对比和片段共享可以改善整体排序，却不能据此证明片段内部定位改善，也不能把预测专家责任解释为事实错误后验。

**非目标**：通过改名称、堆模块、增加没有识别假设的公式或反复选择测试集配置，宣称达到顶会水准。

**约束**：先按无监督主线推进，标签只用于冻结后的评价；保留原始 token 轴、冻结 R4 资源和历史失败记录；本轮不启动远端/GPU实验。纯 CPU 数值检查不等于真实检测结果。少量人工标注校准/训练是待用户选择的独立分支，不混入无监督结论。

**成功条件**：完整可追溯的代码解释；明确的定义、假设、推导、算法、复杂度和反例；相对最近方法可检验的贡献；在新的自然人类标注错误片段上，跨来源和模型验证局部定位收益与成本，并接受独立审查。顶会接收不是本地证明或审稿模型分数能够保证的结果。

## 当前证据与失败点

Oct31 草稿已经诊断 regional ranking 与 local resolution 的脱节，六组测量不是新的独立确认。当前默认 shared 是固定 Beta(1,1) 的精确专家分配；persistent/witness 是共享倾向与持续性的积分模型。`docs/source-reading/THEORY.md` 推导默认 shared 在固定片段内部严格保序，故“改进局部定位”的主张不能靠调整 Beta 先验实现。数学正确不等于事实标签已被识别。

最近的 CORTEX 已有有/无来源隐藏态对比、注意力残差和标签持续性平滑（监督 MLP）；LUMINA 已结合随机文档对照的预测分布差异和内部知识信号。TPA 已做概率分解、来源归因和监督 POS 聚合。单纯把平滑叫作概率图模型、再加一条递推，不构成足够新颖性。

## 两条最小路线比较

**A：无监督诊断与边界论文（当前选择）**。主张：全局指标不足以证明局部分辨；以交换模型保序定理、持续性反例、真实错误片段的成对排序分解形成一套可证伪的诊断。主贡献只有一个：识别借用增益与局部收益的混淆，并提供能定位失败的评价设计。支持贡献是可复现实证和成本报告。复用现有概率测量、span_resolution 与 sealed provenance，不训练新网络。风险：Oct31 版本已经很接近该方向，新增定理可能仍是常识性结果，不能仅凭它宣称达到顶会贡献强度。

**B：冻结语义验证器提供新的局部信息**。把回答按可对齐的原子命题分解，以来源蕴含/矛盾评分产生新的局部观测，再映射到原始 token；同一冻结 verifier 对完整来源与语义保持的来源重写作一致性检查。核心假设是 verifier 在目标域具有语义判别力，不能把它当定理。需要证明收益来自新增事实信息，而非模型/调用预算或隐性标注。相比已有 NLI/LLM judges 具有高度重合，新颖性当前不成立；先做基线，禁止拼接成新默认方法。若允许标注，独立的整例 CRC 校准可提供限定风险语义，但属于设定变化。

选择 A 的原因是它与现有证据和约束一致，可先以零 GPU 成本检验理论，不为摆脱否定结果而堆叠模块。若新的自然标注确认不能支撑有价值的普遍诊断，应该停止该论文主张并重新锚定，而不是堆 B。

## 可实现的算法与输出

输入：冻结的来源—回答、原始 token 轴、来源/回答聚类标识、每个方法的冻结分数和之后解封的人工标签。

1. 在读标签前封存测量/方法/分段/分数的 hashes，保留 unknown token。
2. 对每个混合片段构造所有标签不同的 token 对，报告局部 concordance，按片段/来源预先固定宏平均；同时报告 pooled 指标。
3. 分离跨片段与片段内比较。span-mean、span-centered 是诊断删除对照，既不声称新检测器，也不利用标签定义推断分段。
4. 对 raw full gap、shared、persistent/witness、固定 HMM、LUMINA 采用同一 token 轴；监督 CORTEX 在独立监督表报告，并保持训练/评价来源不交叉。
5. 输出配对差值、按独立来源聚类的 bootstrap 区间、每来源覆盖数、调用数/时间/显存，以及未改善或退化的任务。

评价实现复用 `experiments/span_resolution.py` 和 `experiments/research/sequence_controls.py`。新 CPU 测试验证理论身份，不输出检测分数用于排名。新 GPU 执行前必须有数据/预算/冻结协议，当前不启动。

## 三个验证块与否定条件

1. **理论/实现**：有限状态枚举核对 DP、保序、交叉导数、自证据斜率；任一失败先修推导或实现，不进入真实结果解释。
2. **独立自然错误确认**：新的人类跨度标注来源；主指标局部排序；按来源聚类区间，包含未知/纯片段覆盖报告。若局部/全局分离只在原六组或银标任务成立，收缩主张。
3. **机制与可迁移性**：预先固定的分段、长度、似然温度、backbone 与预算匹配对照。若全部差异由不公平后端/费用或分段选择解释，撤销机制主张。
