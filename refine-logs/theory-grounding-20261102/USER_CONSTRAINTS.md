# 用户确认的研究设定

确认日期：2026-11-02（Asia/Shanghai）。用户原话：**“坚持无监督，真值只用于最终评价”**。

这是当前生效约束，优先于初始问题锚点及历史方案中“待用户选择”的标注训练/校准分支。原始锚点和各轮记录保留原文，不追改历史。

1. 新方法保持无监督检测设定。目标数据的真实支持性/错误标注只在最终评价时解封。给定来源、提示与已有回答仍是合法推断输入；这里的真值指评价标签/参考答案，不是禁止读取来源证据。
2. 解封前冻结方法、参数、阈值规则、分段、随机种子、比较集合、主估计量、排除规则及预测分数；不得用真值训练、调参、选模型/方法、选阈值或做基于标签的风险校准。
3. 无监督参数选择可以使用事先声明的预测证据、一致性或复杂度准则；这些准则与搜索空间也需在最终评价前冻结。数学检查可以使用人工构造的小型fixture，不把它们冒充自然数据效果。
4. 标注校准型CRC、少量真值训练的读出头退出当前主线。现成监督检测器/NLI只作单列对照，不把其监督能力归为新无监督机制；基础模型的预训练、指令训练和任何伪标签来源必须如实披露。
5. 之前已经被反复查看、用于开发判断的六组结果属于探索证据。不能通过重命名或重新切分宣称它们成为未接触的最终确认集。后续如果依据一次解封结果继续改方法，须将这次结果标为探索性，并另设未接触的最终评价数据。
6. 独立人工标注仍有必要，但只承担最终测量目标的工作；不作为训练集、超参选择集或校准集。最终评价可用真值计算局部定位指标、coverage、配对差值及来源聚类区间，不能将这些结果反馈到同一个最终集上的方法选择。

当前方案只完成计算/评价审计，尚未证明检测器改进或顶会就绪。本确认不会补上缺失的事实识别假设，也不改变已报告的研究限制。
