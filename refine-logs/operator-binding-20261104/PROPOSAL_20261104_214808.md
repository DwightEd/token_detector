# H018 提案：来源写入进入 MLP 后，是否出现与原回答相反的局部作用？

时间：2026-11-04 21:48:08，Asia/Shanghai。代码基线：`69835f2767aa49703b596e4de12eb258d78d3417`。

**状态：待科学准入；本文不是实验计划准入、运行许可或方法有效性结论。唯一主候选是“来源注意力写入 → 当前 MLP”的局部直接效应读出。** 本轮只有文献、公式和接口审查；没有执行 tokenizer、模型、标注、评分或新统计，也没有修改 package/state。旧人口均已暴露，不能重新称为未见确认集。

## 1. 为什么选这个问题

5682 的来源明确写 `WiFi: no`，原回答为 `However, they do not have WiFi.`。外部 NLI 对这一支持关系产生高风险，说明有必要区分关系极性和名词匹配，但这个错误本身已经确认，不再复验。5684 的 `street or lot` 有弱析取读法；street=True、lot=False 不能无条件把整个析取判假。该例只提供相同名词在不同 operator/scope 中的观察机会，未许可的读法保留 unknown。

此前主要观察“来源是否影响概率”和“模型关注哪里”。这里新增的问题是：**来源经注意力写入当前残差后，MLP 对原回答的下一 token 增加了什么，是否存在与最终高概率输出相反的局部作用？** 高 attention 不等于正确证据，attention 可以完成语义组合，MLP 也可以做词面复制；不预先把二者命名为 copy 与 truth。

## 2. 时序边界先固定

原 target t 的接收位置为 `r=P+t−1`，始终预测原来的 `R[t]`。同一个 S 和同一个 R 前缀必然产生同一个 prechoice 状态，未来 WiFi 不能反向决定 pre-not 的绑定。post-WiFi 已同时读到 operator 与 property，但也已读到回答词面。因此：

- **主分数只在原 prechoice 行定义**，保留全部原 token；不把 post-property 的投影回同一名词称为该名词的原 conditional probability。
- pre-operator、post-operator/pre-property、property-closed 的轨迹仅作时序诊断。闭合后信息可以用于离线定位，但不能解释已经发生的早期决策。
- 来源 bare key 位于 `no`/布尔值之前时，不能依赖尚未观察到的实际 polarity；完整 field closure 可以访问它，但不保证已编码或使用。来源读取 query 仍需新捕获，不能由旧回答历史 attention 代替。

## 3. 唯一主读出：全部来源写入的 MLP 局部效应

固定主 scope 为 `encode_source` 的**全部实际 source_mask token**，不包含问题、chat token 或 R。不从结果选择字段、层、头或正负方向。对每层 l、原接收行 r，令：

\[
m_{lr,S}=W^O_l\operatorname{concat}_{h=1}^{32}
\left(\sum_{s\in S}a^{lh}_{rs}v^{lh}_s\right),\qquad
x^{mid}_{lr}=x^{pre}_{lr}+a^{out}_{lr}.
\]

这里的 attention、V、GQA/RoPE、W_O 都取本次 native forward 的真实定义。`m` 是未归一化的来源子集写入，不能改成 source-only softmax；包括所有物理头，并保留每个头的原数据。若 W_O 存在 bias，只能将 bias 计入全 attention 写入一次，不能分给每个字段；当前 Llama 配置必须重新核对。

定义只改变当前 MLP 输入的局部重放：

\[
\delta_{lr,S}=\operatorname{MLP}_l(N_l(x^{mid}_{lr}))-
\operatorname{MLP}_l(N_l(x^{mid}_{lr}-m_{lr,S})),
\quad D_r=\sum_{l=0}^{31}\delta_{lr,S}.
\]

`N_l` 是原 post-attention RMSNorm，MLP 使用原权重、原精度、官方实现。native 的 attention/residual 与其他层输入全部保持原记录；只在局部重放中删去这条 MLP 入边。**D 是固定 native 背景下局部增量的和，不是传播后的新世界。** 各层可处理同一信息，不能声称各层贡献独立或把 D 当作重建出的 source-free residual。

令 H_r 是原 final RMSNorm 之前的完整残差，g 为原 final RMSNorm 和完整词表 head。唯一原 token 风险接口为：

\[
e_t=\log\operatorname{softmax}(g(H_r-D_r))_{R[t]}
      -\log\operatorname{softmax}(g(H_r))_{R[t]},\qquad
\operatorname{risk}_t=\sigma(e_t).
\]

正 e 表示：删除这些局部 MLP 增量后，原 token 的概率反而上升。**这只证明指定读出中的反向作用，不证明 token 为假。** sigmoid 的斜率固定为1，仅提供单调、有界接口；不是校准后的幻觉概率，不拟合目标标签。保存 e、两侧完整词表 logits/logp、D、每层 δ 和原坐标；若最终实现因资源改成分块 head，必须先独立资格，不在本提案中默许。

主 scope 使用全部来源，故每个有效原 token 都有输出，无需 R 极性解析或人工关系标签，不采用 max/权重融合。空来源或无法匹配原轴须保留 explicit unknown；模型/仪器失败必须失败封存，不能伪填成已完成。若日后采用0.5 unknown fallback，分母和 unknown mask 均应保留并在独立协议中冻结。

## 4. 公式真正支持的结论

小扰动的一阶展开是：

\[
e_t\simeq-\nabla_{H_r}\log p(R[t]\mid H_r)^\top D_r.
\]

这说明风险方向依赖 D 与**该原 token 相对全词表分布**的关系，不能从 δ 的范数、某个 attention 权重或对名词的 cosine 推出。最终 RMSNorm 也会改变其他词的相对分母；必须保留完整词表概率，不能只看两个候选的归一化比例。e≈0 不证明模型没有极性信息，可能存在抵消、冗余或与当前 token 读出正交。

拟检验的假设是：一部分不兼容回答已经触发来源条件相关的 MLP 反向作用，但其他路径仍推动原回答；该反向作用可成为原轴风险信号。它需要实证的支持/不支持方向检验，**不是以上公式给出的真值定理**。正确句也可能在词汇竞争中受到来源相关抑制；错误句也可能被所有路径一致支持。

## 6. 直接相关的一手研究：重合与剩余空白

1. [Zhou et al., **How Language Models Process Negation**, ICML 2026/PMLR306](https://proceedings.mlr.press/v306/zhou26bq.html)，及[作者全文](https://arxiv.org/html/2605.03052v1)：已发现 not 信息先移至概念、attention 构造否定表示、下游 MLP 放大，以及晚层 shortcut 可覆盖这些机制。研究对象为 Llama-3.1-8B **base** 与 Mistral；不能拿它直接证明本 Instruct observer。它已经覆盖“模型有否定能力但被另一机制压过”的一般叙事，本提案不能将其包装为新发现。剩余可检验问题是这些 source-conditioned 局部作用是否能在自然原 R 上提供检测/定位或成本价值。
2. [Bhaskar et al., **Finding Transformer Circuits With Edge Pruning**, NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/20fdaf67581e6d7157376d1ed584040a-Abstract-Conference.html)：组件间 edge 分解、干预和 faithful circuit 并非新概念。这里既不搜索稀疏 circuit，也不以复现模型行为等同事实正确；局部 edge 与直接效应本身不能单独成为新颖性。
3. [Kletz et al., **Polarity inversion operators in PLM**, CoNLL 2025](https://aclanthology.org/2025.conll-1.20/)：在 BERT 上训练外部 MLP 操作 contextual embedding，极性变换仅部分成功，递归不恢复原表示。它不许可一个跨层统一的线性 negation direction，也不许可将本文局部 δ 直接命名为“否定向量”。
4. [She et al., **ScoNe**, ACL 2023](https://aclanthology.org/2023.acl-short.154/)：使用至多两个否定及六元 contrast sets 区分否定表面出现与真实 scope。它要求本提案保留同词不同 scope、无关字段及非 not/no 表达，不能只以 not/no 同现交互晋升。
5. [Xie et al., **Factual Consistency Evaluation for Text Summarization via Counterfactual Estimation**, Findings EMNLP 2021](https://aclanthology.org/2021.findings-emnlp.10/)：CoCo 已用来源 mask 前后的原摘要概率差评价 factuality，且采用独立 scoring model。单独改为 polarity flip、logp 或 source field 不是已确认的新方法。
6. [Shi et al., **Trusting Your Evidence: Hallucinate Less with Context-aware Decoding**, NAACL 2024 short](https://aclanthology.org/2024.naacl-short.69/)：CAD 已使用有/无 context 的对比分布改善生成。本文保留既有 R、比较内部入边，应用契约不同；但概率对比、无训练和抑制先验都不是新的宽泛贡献。

本轮没有发现可直接断言“该具体全来源→MLP原轴风险已被发表”的一手证据；**没有发现不等于新颖性已成立**。当前仅有可区分的候选观测，尚无顶会贡献结论。

## 7. 最小审查门：把可运行、机制和检测分开

**第一门只做两条原 R 的工程/描述性资格。** 如单独获得准入，5682和5684最多各1次 native full forward；同一 native 源码/权重驻留期间重放当前 MLP，不重跑旧 NLI 或 legacy概率现象。所有原 target 都输出主 e。m=0/no-op 必须复现 native MLP、H、完整词表概率；attention 子集相加必须重构 native AV/O；保留 norm-matched固定随机方向 sham（固定种子、每层每行相同范数），检验 generic removal/RMS/head 效应。全部原数据先落盘再过门；任何数值失败停止，不调精度、阈值、层或 scope 救援。这两例不许可支持/错误区分或 AUROC。

**第二门才检验符号假说，须另行冻结精确文本和资源再准入。** 一个可能上限为3个 source 状态（native、相关字段 polarity flip、无关字段 flip）×2个 R polarity×2套 operator 表达=12个完整条件。原5682若字节完全相同必须复用；加5684工程例后，最多13个不同 native forward。每条件完整原轴 native/主读出/sham 至多3次完整词表 head，整体至多39次；MLP replay 次数、最大行数和资源须在代码前单独计入，不以“0个额外model”掩盖计算成本。该上限只是提案，未许可任何调用。

这组对照存在一个已知前端缺口：source13603 只有一个 `no/free` 同域可用性 leaf；无关布尔 False→True 不是同词域 control。WiFi no→free 同时改变可用性与收费，不能写成唯一语义变量。因此不能把上述12条件自动当作通过 owner-specific 判别的设计。需要先冻结一个合法同域、不同 owner/property 的词面匹配对照，或明确限制能拒绝的 null；不能伪造原来源中不存在的第二个 WiFi leaf。若须使用构造来源，只能证明该构造 assay，不能承接自然同源准确性。当前没有以新增世界消除这一缺口的许可。

## 8. 值得进入完整检测评价的条件

严格的 typed source lookup 在显式 WiFi 例上已经足够；不能以赢这一例宣称内部更可靠。实际价值至少要满足一项：不手工给 R polarity 的隐含/释义表达上更可靠；同一原句内定位比整个句子广播更好；在同一前端/全文证据条件下，以更少完整 observer forward 达到相当检测效果。主线必须保留强直接文本基线与原R定位基线，不盲融合到 R4/V3。

若阶段性门通过，才冻结完整900原回答/178343 token 的新分数，独立审计后再开最终 GT，用现有 AUROC/AP、配对 source bootstrap、固定报警预算的 FN/FP、coverage和完整成本评价。已暴露900只算探索验证，不由当前两例或人工 assay 推出0.8、自然AUROC或泛化。若新分数只反映普通 source dependence、名词频率、norm damage或重新格式化，它不应晋升。
