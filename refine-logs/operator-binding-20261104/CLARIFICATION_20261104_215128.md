时间：2026-11-04 21:51:28，Asia/Shanghai。补充 `PROPOSAL_20261104_214808.md`，不覆盖该草稿；主公式、符号、全部来源 scope 和 NOT_ADMITTED 状态均不变。

1. **H_raw 必须从 native final RMSNorm 的输入抓取。** 官方 `last_hidden_state` 和现有 observer hidden 接口通常已经做过 final norm，不能直接减 residual-coordinate 的 D 再重复 norm。必须在同一次 forward 检查 `native_final_norm(H_raw)` 复现原 `last_hidden_state`，其完整 head 复现原 logits/logp；没有这项身份门就不计算风险。
2. **拆开 token logit 与全词表分母。** 每个原 target 保留 native/counterfactual 的 `z_y`、完整 logsumexp 与全词表 logits。精确恒等式是 `e=(z_cf_y−z_native_y)−(LSE_cf−LSE_native)`。这可区分 token logit 变化与其他词竞争造成的变化，但二者都不是语义真假证明。
3. **保留扰动尺度。** 每层每行保留 `||m_S||/||x_mid||`、`||δ||`，以及 `||D||/||H_raw||` 与 native/counter final-norm 的分母；零范数单独标记，不以任意 epsilon 修复数据。范数只作扰动/数值报告，不能看结果后成为风险权重、筛选规则或新的 threshold。
4. **自然两例工程门有明确上界。** 2次 native full forward；每次32层、全部原 R prechoice行各作一次 source-removal MLP replay和一次固定norm-sham replay，共128个额外 MLP调用（每调用可批处理该例全部原行）。no-op replay再32层×2例，共64个MLP调用，故本门总上界192个额外MLP调用；它们不计作完整 model forward但必须单列耗时/输入行数。每例 native/source-removal/sham 三个完整 head，共6次，no-op只复用native H身份检验，不再增加完整head。若实现或资源需要额外head、拆MLP调用或重跑，先回到合同审查，不能自动执行。
5. **不要以信息被 source Mask 删除为结论。** MLP局部重放仍保留native attention/residual的其他来源信息及更早层效应。这里隔离的是当前来源写入到当前MLP的一条计算入边，不是清空模型的来源知识，不是full downstream necessity实验。固定随机norm-sham与真实来源写入都可能离开自然流形，控制失败即停止机制晋升。
