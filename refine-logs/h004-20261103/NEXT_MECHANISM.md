# 下一项判别：完整回答的判定负担，是否掩盖了本可识别的局部关系错误？

2026-11-03 01:23 +08:00。提案状态，未实现、未调用模型、未读取本轮 gold、未改动运行代码或活跃安装目标。H004 正在运行；它的严格来源语法仅覆盖三条完整结构化来源，不能把未转换的构造控制说成类型干预成功或失败。本文不使用 H004 的评价结果选下一方法。

## 一个主张及可推翻的解释

**拟检验主张：对一部分来源绑定错误，3B 观察器已有局部辨别能力，完整回答的多命题判定负担会掩盖该能力；把判定目标改成自动生成的精确文本单元，可以恢复局部的非支持信号。** 主模块只有“判定范围”；来源、原回答、模型、量化、全部六种标签分配及原始预生成上下文固定。先使用原始来源，不根据 H004 标签选 A/B/C/D 中最好的表达。

生成机制给出的动机有限而具体：自回归模型的 `P(y_t | source, y_<t)` 条件中已经含有自己的早先输出。一个被错误主体/年份绑定的前提，可以使后续解释在语言上连贯而仍不忠于来源；高 teacher-forced 概率只说明在这些条件下容易继续。已有研究展示了早期错误带出后续错误，以及模型能单独识别自己先前写出的错误；见 [**How Language Model Hallucinations Can Snowball**](https://proceedings.mlr.press/v235/zhang24ay.html)（ICML 2024）。它是动机，不证明本项目原生成器的失败原因。

本提案直接改变的是观察器判定范围。即便成功，也只能说明“这些冻结输入上的判定能力被范围影响”，不能证明原生成错误由注意力稀释、前缀污染或某个内部状态造成。没有原始生成器的对应干预及可靠身份，就不能跨越这个因果边界。

竞争解释是：观察器根本不能可靠解析目标实体—关系—数值绑定，或不能区分未报告与否定；更小的判定范围也不能修复。在最简、明确指称、同词袋的关系交换对上，焦点读出若仍不能产生正确方向，就反驳“仅靠范围定位足以解决”的主张，而非继续改名扫描提示词。

## 精确单元，避免自由位置提议

不调用模型产生 offsets、改写事实或抽取三元组。对原始回答 `y` 用一个冻结字符扫描规则生成有序、不重叠、覆盖 `[0,len(y))` 的区间 `U_i=[a_i,b_i)`，并验证逐段拼接逐字符等于 `y`。它们称文本单元，不称已证明原子命题。

可实现的首版规则是：在换行和 `。！？；` 后结束单元；ASCII `.?!;` 后为末尾或空白时结束，且句点位于两个 ASCII 数字之间时不切分；紧随边界的空白归前一单元；最后残余字符归最后一单元。空白回答保留一个单元，空回答保留零个输出 token。所有标点、空白、引用和重复句子保留独立原始位置。缩写如 `Dr.` 和引号内分句会产生较差单元，这属于预先声明的风险，不按标签逐例修补。过长单元按未知处理，不偷偷截断或增加另一套窗口算法。

每次请求仍包含完整来源、完整原回答和原始预生成上下文；另提供精确 `focus_text=y[a_i:b_i]`，程序核验该位置及文本匹配。模型只返回 A/B/C 中一个标签，不生成位置或理由。指令明确：仅核验焦点单元在完整回答中的原意；其他回答文字只可帮助理解指代和范围，不能充当事实证据；主体、属性、账户、时间及量值必须与来源绑定；缺证据不等于冲突；合法、前提完备的推导仍可支持。指代无法消歧、单元非完整命题或缺少必要问题时选择 unresolved，不自行补事实。

这里不删除来源证据，不重置生成前缀，不修复回答，不实施值盲重建，也不把模式匹配成功当证书。完整上下文可保留跨句指称，但也可能继续干扰观察器，因此焦点效果不是预定结论。

## 理论义务与删除影响的边界

令 `E_i` 表示按完整篇章原意理解的单元得到来源支持。若语义完全可分解、每个单元的指称已确定且没有遗漏跨单元关系，则完整支持满足 `E_all = ∧_i E_i`。这只是逻辑分解；不保证 LLM 分数实现它。目标风险固定为

\[
 r_i=1-\bar q_i(S),\qquad
 \bar q_i(S)=\frac{1}{6}\sum_{\pi\in S_3}q_{i,\pi}(S).
\]

`r_i` 是条件标签空间的非支持读出，不是校准后的幻觉概率；contradicted 与 unresolved 原始分数、全词表标签外质量、所有排列和成本一起保存，不拟合阈值，不混合 R4/V3。

另一候选是删除单元后的整答 log-support 影响

\[
 \Delta_i=\log q_S(y\setminus U_i)-\log q_S(y).
\]

仅当整答支持概率确实等于正确联合概率，并且删除不改变其他命题原意时，差值才对应 `-log P(E_i | ∧_{j≠i} E_j,source)`。进一步假设条件独立，才等于 `-log P(E_i|source)`。现有未校准三类读出不满足这些保证。删除若改变指代、前提或问题的回答范围，这个等式不再适用。

反例：回答有两个彼此独立的错误句子，理想硬判定器对原答及分别删除任一句后的回答都判非支持，两个删除效应都为零；log 版本则出现零概率或近零饱和。另一个反例是“甲击败乙。他获得冠军。”删除第一句会改变第二句的指称条件。故删除影响只作为预先固定的诊断对照，不作为本轮主定位器，不从目标 gold 比较后挑选赢家。若试验保存有限值，应使用三标签 logits 的稳定 log-softmax，再做六排列的 log-mean-exp；不要靠任意 epsilon 或裁剪隐藏饱和。

精确文本分割也有反例：一个单元包含“甲在北京出生并于 2001 年到上海工作”，只错第二个事实时，整段会共同得到风险，不能实现词级精确定位。实体指代错误甚至可使每个单独事实看似真实而合起来错误；[**Merging Facts, Crafting Fallacies: Evaluating the Contradictory Nature of Aggregated Factual Claims in Long-Form Generations**](https://aclanthology.org/2024.findings-acl.160/)（ACL Findings 2024）已展示实体歧义下的此类边界。不能把句级广播包装成 token 机制已经解决。

## 最多三个必要比较

1. **整答 vs 单元焦点。** 对事先冻结的完整人口及全部自动单元执行；整答请求若与 H003 精确相同则复用。焦点请求保留完整来源和原回答，只改变评价目标。报告每个单元及全部 token，不用已知错误位置筛单元。旧 34 答仅作已暴露的探索材料，不能用于选分割规则、模板或阈值，也不是新确认集。
2. **新的关系交换 × 判定负担控制。** 在观察前冻结全新、与目标标注无关的规则生成材料：两个实体、两个事件或账户、两个年份/数值，正确和错误版本保持相同词袋；目标句显式命名，不使用代词。把同一目标句置于 0、4、12 个来源明确支持且不共享目标实体的干扰句中，位置固定且对两端相同；正确端与错误端均保留。若焦点对最简关系交换能分辨，并在增加干扰时保留方向，而整答方向变弱，支持“判定负担”解释；最简焦点也失败则说明该接口/观察器能力不足。一次成功方向不代表自然任务 AUROC。这里比较的是新范围干预，不重算旧 H003 同词袋现象。
3. **同一新控制人口上的删除影响诊断。** 同时包含一个错误、两个独立错误，以及一组跨单元指代/前提依赖控制；不按结果挑案例。检查删除影响是否在多错误条件下饱和、是否对正确依赖单元误报警。它检验局部影响读出的可识别性，不加入第二个主方法，不据其表现重选焦点方案。

三组比较使用同一冻结观察器和六排列；没有更强模型、算术执行器、自由 claim extractor 或证据检索模块。成本随单元数增长（整答 6 次，焦点每单元 6 次，删除仅限定诊断人口）；按实际前向、输入 token、拒绝和缓存复用报告，不宣称等成本。资格结果在输出全部封存后才与预先封存的构造真值核对；设计依据生成规则而非目标 benchmark 标签。失败时保留负结果，不在同一人口反复调提示词。

## 无监督全 token 投影与未知规则

冻结单位风险后，使用原始回答的同一 tokenizer 和原生 token ID/offset 轴。对字符区间非空的 token `I_t`，定义 `r_t=max{r_i: I_t∩U_i≠∅}`；边界 token 同时覆盖两个单元时取较大风险，不按 gold 或任务调权。重复 BPE offsets 保持原始 token 独立身份；不得重分词后换评价轴。

输入过长、某单元不获评分、解析/身份失败及无法得到有效 offset 时均显式记录工程 unknown。若冻结为完整 token 排序器，预先规定这些位置风险为 1，并保存它是保守 fallback 而非模型发现错误；主要全 token AUROC 仍包含它们，同时给出真实评分覆盖率与 fallback 数。仅官方数据合同本来未知/不可对齐的标注沿用原评价规则，不因方法失败额外删 token。合法 scored 单元的 unresolved 已包含在 `1-q_S` 中；低标签质量只做诊断，不能事后用阈值剔除困难位置。所有 token 的原身份、分数或 fallback、来源、单元和状态均要封存。

这会把部分正确词一并赋高风险，是明确精度代价。若全 token 投影效果差，不能改成只报错误实体、只报有证据的 token 或任务最佳包络。完整六任务、HalluRAG 含答案主组及其余发布分层保持；六任务各 0.8 的目标仍需实际评价。新确认人口须独立确定，不能重新切分已看标签的人口冒充未接触数据。
