# 组合方法实验计划

**问题**：原 token 轴上定位不受给定来源支持的内容；现有 pooled 提升不能证明局部识别改善。
**方法论点**：以 V3 为统一概率推断骨架，检验一种受控关系观测是否补足整体来源删除缺失的信息，并通过完整因子对照验证组合价值。
**日期**：2026-11-02。**状态**：PROPOSED_NOT_RUN；候选不是已验证的 V4。
**约束**：无监督；真实任务标注仅用于一次冻结后的最终评价。已有六组均暴露，不再担当确认集。已恢复原稿/账本的历史结果不能替代此协议。
**模型与理论**：[组合设计](../docs/source-reading/INTEGRATED_DESIGN.md)；[V3 基础](../docs/source-reading/METHOD_V3.md)；[全部已恢复主比较](../docs/RESULTS_CURRENT.md)。

关系来源扰动本身已有失败先例，本计划只提出资格收紧与V3融合的再检验，不宣称新信息已发现或新颖性成立；没有新证据则不进入效用宣传。

本计划响应用户“结合优点共同设计”的纠正：算法可以联合设计；模块分离是为了检验贡献，不是强制独立写成数篇工作。旧锚点与旧审查保持历史身份。本计划不宣称之前研究门槛已通过。

## Claim Map

## Experiment Blocks

### B1：转换器资格与理论正确性

- 主张：C1 前置，不测试检测准确率。
- 数据：独立无标签表格来源；每个适用源测试完整固定转换；闭合合成世界用于软件/逻辑合同核验。真实任务标签不读取。
- 比较：原来源 S、来源删除 A、关系变换 B、保持关系的 sham。B 仅交换同列同显式单位/类型单元格；规则不读取回答、风险分数或评价标签。
- 指标：词项/数值多重集、单位/类型、表格结构、编辑位置、目标绑定改变、非目标绑定保持、适用覆盖与失败类别；数值轴完全一致。
- 设置：原 token、完整输入、同模型后端与精度；B不适用时固定 qB=qA，直接调用原V3生产分支保证逐位退化，避免等价算式舍入差。交换两值改变目标绑定集合，不声称仅动一个事实。禁用历史已失败的自由文本解析器补覆盖。
- 理论：归一化凸混合；退化恒等式；发射下界；枚举验证联合积分；分数对发射的 L1 误差界。有限小段 oracle 不复制生产DP。
- 成功：封闭语法的全部合同检查通过；对适用样本零已发现目标/非目标合同违例；非零适用来源数及其区间公开。自然语义效度不由软件PASS保证。
- 失败：任何系统性单位/绑定错变都阻断检测效能主张；先记录失败，不在标签上救援。若只覆盖表格，贡献范围固定为结构化来源。
- 图表：主文干预合同与覆盖表；理论和拒绝样例附录。
- 优先级：MUST-RUN。

### B2：来源 × 历史的受控机制实验

- 主张：C1 的预测响应，尚非自然事实识别。
- 数据：B1无标签来源及固定闭合关系例；最终自然标注不参与准入或权重选择。
- 系统：S/A/B × full/local 历史；sham/full 与 sham/local；等长非关键信息替换控制。B/sham使用相同固定随机化预算。
- 指标：目标与未触及单元位置上的 logp 差、完整预测分布差、full/local 交互、对格式/位置/长度的敏感性；同时报告全部负例和覆盖。
- 设置：预先冻结哈希选取的诊断来源与3个随机扰动种子；保留全部种子，不从效果挑最好。full/local 的历史内容、长度和绝对位置差分别对照。
- 成功：预先规定的目标绑定影响方向在合成闭合正控制中成立；sham不产生同等响应；非目标响应及不确定性如实报告。不把该门槛当自然正确率筛选器。
- 失败：若 B 只比 sham 更不流畅、或 full/local 效应由长度解释，撤销关系/历史语义解释。不得把差中差命名为已识别的中介因果效应。
- 图表：主文受控响应矩阵；代表性失败例必须由预定规则取。
- 优先级：MUST-RUN。历史维度用于机制审查；当前候选只采用 full，不额外引入历史专家混合。

### B3：完整因子消融与组合必要性

- 主张：C2；先保证数学退化与数值身份，在最终评价才测效用。
- 数据：同一封存原 token 概率；最终人群所有配置分数一并封存。
- 8配置：观测 O∈{仅A, A/B等权混合} × 持续 P∈{c=0, V3积分c} × 发射 E∈{纯U, 半S半U}。
- 必要补充：新观测 u 单独使用；原V3；qB=qS精确控制（风险专家0.75qS+0.25qA，无新观测）；同预算 A/sham 组合；固定局部HMM；同一新观测上的旧关系world_shared。旧算法需要的null数量、适配合同与额外调用在冻结前说明；适配版不能冒称旧算法原样复现。V1/V2/原V3对应明确角点，命名按实际发射/先验，不混同。
- 指标：预定来源等权局部 concordance 为主；pooled AP/AUROC、pair-weighted within、top5%召回为次。报告每次删除对完整配置的配对差，以及完整因子的交互差与区间。
- 设置：全部均匀专家权重、Beta先验和span规则在真值前冻结；同一观测对所有读出复用。推断随机性为0，不伪造3个确定性训练种子。
- 成功：与原V3、观测单独及qB=qS基线相比，预定局部主效应均为正、确认区间下界>0；全局AP符合B4非劣约束。若qB≈qS，增益可能只是改混合比例，须撤销新关系信息解释。若某模块删除无损，候选应缩减，但只能在下一份未接触确认集检验缩减版。
- 失败：只有全局AP增益、局部无益，不支持定位主张。某项消融下降只支持该配置下的边际作用，不能证明独立、普遍或唯一因果作用。
- 图表：主文8配置表和两项关键交互图，完整区间附录。
- 优先级：MUST-RUN。

### B4：独立最终自然支持性评价

- 主张：C1/C2最终效用。
- 数据：必须新来源组，不能重切已暴露六组。结构化关系为主任务；新QA/Summary作为外部适用性与退化检查，不能未覆盖却宣称关系收益。金融silver、HalluRAG句标签仅附表。
- 最低工作规模：每个拟宣称适用领域先锁定至少100个新的来源组；评价完成后报告实际产生局部正负对的来源数。此数是启动预算，不是功效已保证的样本量；不足则结论不确定，不能据标签挑来源扩充到显著。
- 标注：两人独立、分歧仲裁；provided-source supported / contradicted / absent / uncertain + 原字符边界。后两种有明确定义；uncertain排除有标签指标但保留coverage。不得用于训练、权重或阈值。
- 主估计量：每来源汇总同片段正负对concordance，再对具可评价对的来源等权平均；明确条件总体、纳入率和各来源对数。区别于当前pair-weighted函数，需先实现另名函数和独立枚举。
- 配对：同一来源作为重采样组；若来源来自同公司/报告，按更高共享母体聚类。10000次配对bootstrap，种子17。最终锁定D个主领域、2个backbone后，主家族为D×2×3个局部差（V3、u单独、qB=qS）及D×2个AP非劣差，共K=8D；所有方向/比较先登记。
- 多重性：主家族统一用双侧Bonferroni百分位区间[α/(2K),1−α/(2K)]，α=.05，检查下界。它是来源bootstrap的渐近近似、非有限样本精确保证；不能称Holm调整后的区间。若尾部有效抽样精度不足，增加预先规定的bootstrap次数而不改变模型或源集合。其余因子交互、任务和稳健性区间标为描述性。
- 成功标准：冻结组合相对V3、u单独及qB=qS的局部差，两backbone在每个宣称的主领域均满足校正区间下界>0；pooled AP候选−V3的同家族区间下界>−0.01（事先声明的绝对容忍界）。全部公开AUROC、AP与漏报情况；不从未通过的领域中挑好看子集改主声明。
- 跨模型：Llama与Qwen使用相同规则、各自tokenizer，分别评价不跨轴合并。两者方向都支持才宣称跨观察模型；否则限定范围。
- 设置：先锁全部代码、输入、来源身份、转换器、种子、比较集合、参数、评分与排除规则再读真值。最终失败后若改方法，本次全部变探索，下一确认集另锁。
- 图表：主表局部+全局、覆盖、成本；所有源级差值附录。没有混合跨度的任务为不可评价，不填默认0.5。
- 优先级：MUST-RUN。

### B5：简单性、预算与稳健性

- 主张：C2不由额外预算解释；固定基础模型为唯一现代原语，不增加agent/训练。
- 数据：与B4同一锁定人群；成本测量不读标签，稳健变体随主方法一起冻结并只作报告。
- 系统：等预算sham、u单独、固定局部HMM；LUMINA全成本；R4的local/route/参考步骤单独计数。监督CORTEX只作另列参照。
- 指标：真实backbone forwards、处理token、峰值显存、墙钟、读出CPU时间、每来源额外成本；两种固定span上限32/64及人工格式保持变换的稳定性。
- 成功：核心局部效用在同预算参照下保留，规则跨模型不改；某个额外模块无贡献时公开结果，下一轮删减。无法把更多调用与新信息分开时收缩贡献主张。
- 图表：主文成本表，分段/格式稳健性附录。
- 优先级：成本MUST-RUN；额外backbone/领域扩展NICE-TO-HAVE。

## Compute and Data Budget

- 没有可用GPU实例，本轮不启动LM实验；主张与执行状态分离。
- 新观测主包：S/A/B共3个完整前向/答/模型；sham预算对照另1个。2×2×2读出共享同一包，无8倍LM成本。
- full/local诊断仅锁定的小包执行，约4来源条件×2历史条件×2模型×诊断答数；不得把“两个世界”写成实际调用数。
- LUMINA需要随机来源和内部状态，另记实际前向与存储，不能混入3世界预算。可复用S仅在字节/配置一致时声明。
- GPU小时暂不捏造：先20答pilot测各模型τ秒/答、预填/投影/序列长度，再用总处理量估计并给长尾余量。主包粗公式4×2×N×τ/3600小时，τ须对应单世界实测定义。
- 最大瓶颈是合法关系转换、全上下文观测与新的来源级人工标注，而不是CPU消融。
- 基础模型的预训练/指令训练如实披露；任务真值无训练/选择用途。

## Risks and Mitigations

- 旧方法关系扰动已经失败：必须有新资格与响应证据；若重复旧失败，不继续堆推断。
- 结构化覆盖有限：公开全总体、适用子总体及fallback；不扩张为所有自由文本任务有效。
- 理论只是工作模型：不把latent专家责任称为事实错误概率，也不从Lipschitz界推出AUROC提升。
- 新来源可能与旧公司/文档重叠：内容哈希及母体身份审核；发现污染先公开，不能只改split名。
- 消融不足以证明模块普遍有效：报告交互及负结果，最终设计由冻结合同决定，解封后不挑赢家。
