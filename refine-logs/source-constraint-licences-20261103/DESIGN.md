# Source-only constraint licences: frozen extraction contract

2026-11-03. This is a label-free source inventory, not a detector, QA run, new H004 eligibility experiment or natural performance estimate. It does not establish the semantic bijection assumed in H009/H014.

## Population and information boundary

Use all 900 ordered RAGTruth_Data2txt inference records in the existing full-input-inventory-20261103, with its recorded 150 distinct source IDs. Bind that inventory metadata file, the exact input SHA256 and ordered-ID SHA256 before opening source values. Decode only the root fields id, source_id and source. All other JSON values, including response, prompt and any labels or scores, are consumed by a lexical skip routine and are never decoded, retained or printed. Hashing the complete input bytes is provenance, not byte-level isolation from unselected fields.

Do not open original release response files, evaluation_only, predictions, H004 performance outputs, new datasets or models. The H004 source parser code and public inference inventory metadata may be read. No tokenizer, NER, API, GPU, benchmark labels, response analysis or candidate answering is allowed. Record every original ID and its source identity; compute source statistics once per distinct exact source string, with the 900-record repetition counts retained.

## Frozen mechanical rules

1. Reuse experiments.research.typed_source._parse with its existing pinned limits, decimal-token preservation, duplicate-key rejection and explicit JSON/Python-literal syntax result. No preprocessing, strip-based matching, key correction, number conversion or fallback parser is added. Rejected sources are retained with their original hash and parser reason, all licences unknown.
2. Traverse the accepted typed tree in its original object/list order. A path is an ordered array of original string keys and integer list/tuple indices; key type and index type remain distinct. Count root kind, each object and its direct keys, every container's cardinality, every scalar typed value and path, nulls, empty strings, whitespace-only strings and empty containers. Boolean false and numeric zero are values, not missingness.
3. Unique object keys and indexed paths license only an unambiguous structural path-to-node/value lookup. Repeated bare field names under different parents are counted separately. Remove integer array indices solely for a declared field-pattern diagnostic: a pattern may have multiple occurrences, repeated values or differing values. This removal never merges real paths or asserts a global functional dependency.
4. For all scalar leaves, compare exact typed values; numeric token spellings remain unchanged. Report whether the full scalar-leaf path-to-typed-value mapping is injective, together with all repeated-value groups and paths. Separately compare the complete nonempty string-leaf domain, with no case, Unicode, whitespace, alias or unit normalization. Unique strings license an invertible lookup only within that exact finite source representation; they do not identify semantic roles.
5. Distinguish exact repeated string-leaf values from substring occurrence. For each distinct nonempty string value, count all overlapping exact occurrences across decoded string-leaf texts, including its own leaf, and separately in the raw serialized source. Escaping can make a decoded value absent from raw serialization; keys or incidental text can add raw occurrences. Neither count is a semantic fact count or an entity-identity test. Empty strings have no substring count.
6. Lists/tuples with cardinality greater than one are structural multivalue containers; singleton and empty containers are retained separately. No comma-separated scalar is split. Count strings containing comma, semicolon, pipe or newline as unassessed lexical diagnostics only. Literal strings whose casefold is exactly one of unknown, n/a, na, none, null, not available or ? are counted as sentinel-like strings, without deletion or a semantic missingness claim.
7. Report mechanical licences separately: structural path lookup; injectivity of the complete exact typed scalar map; injectivity of the complete nonempty string-leaf map; and uniqueness of substring occurrences. Null/empty/sentinel-like status, closed-world completeness, alias equivalence, arithmetic closure, predicate arity, cross-field semantic functional dependency, and source-to-response role alignment remain unassessed. No source is admitted as a semantic person/event bijection from JSON shape or value uniqueness alone.
8. Response mentions all facts, covers the complete candidate domain, preserves source cardinality, or is a permutation of source values is never assumed or tested: response is not read. A source field with one value licenses no requirement that a natural response mention it. A two-valued field or two distinct strings is insufficient to impose a two-role bijection.
