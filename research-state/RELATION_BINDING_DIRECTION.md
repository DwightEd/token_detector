## 要回答的问题

来源为“甲公司收入100万，乙公司收入200万”，回答为“甲公司收入200万”。分别测量：生成概率、对数值 occurrence 的关注、来源事实的主体/条件归属、关联在回答过程中的持续性。四者可能在错误回答中同时很强，不能先把它们定义为正确性。

将来源候选单位保留为 `(主体, 谓词, 值, 时间/范围/极性, 原文区间)`。相同数值的不同 occurrence 分开，允许合法多对一、计算和多跳；没有足够语义许可时保留 unknown，不用最近实体或全局双射补齐。

当前首要判别是：**回答条件接收位置到数值预测接收位置，检索的事实所属主体是否改变？**

| 竞争解释 | 候选观察；均不是单凭模式就可确认的机制 |
|---|---|
| 条件没有约束检索 | 条件和数值前都偏向乙的事实 |
| 检索时发生所属主体切换 | 条件处偏向甲，预测数值前转向乙 |
| 值或后续读出出错 | 两处仍偏向甲，最终数值却为200 |
| 回答历史的自我强化 | 错误出现后关联更稳定；prechoice 与 post-token 分开 |

所有者变化只是候选诊断，不能直接当作覆盖所有幻觉的分数。需要固定数值和位置、改变所属主体的对照，以及 Q/K/V 分离的角色替换；不再重跑笼统删来源、prefix reset、旧角度/whitening 或角色问答榜单。

事实剖面首先保留完整fact ID及其主体、谓词、时间/范围/极性；主体剖面只是边际诊断。若先把同公司事实合并，“甲2024收入100、甲2025收入200”的时间错绑又会消失。句子边界也不自动等于事实边界。

另须区分关系错误与唯一错误token：示例中改“甲”为“乙”或改“200”为“100”都能修复支持关系；没有额外问题/意图约束，不能断言只能是数值词错。风险首先针对组合关系，进入检测前再冻结其投影到原token/span的规则；不得读取发布标注后反选位置。关系级诊断与严格原轴检测分别报告。

## 现有数据真正允许什么

- QA TEST900 有 block15 双世界坐标。Q/K 是 **RoPE 前**投影；重放必须恢复原 RoPE/GQA、位置、缩放和因果掩码，再对已存 attention/group mass 做数值资格检查。不得直接 raw Q·K。
- 来源阻断 hook 安装于全部层，当前 early-stop 执行0–15；它阻断非 source query 对 source key 的读取，source query 保留因果读取。只归档第15层，不能称第15层单独的因果干预。
- nodes/query 只有回答 T+1 行；全输入 K/V 不等于完整来源 Q/hidden。当前缓存不能独自证明“读取时形成关系印象、回答时 recall”的完整电路。
- early-stop 没有最终模型生成概率。使用其他 native cache 的 logp 前，须核对真实 prompt/answer token IDs、位置、观察模型和 backend；不能拿第15层 lm_head 投影冒充生成概率。
- 这些坐标来自冻结 Llama3.1 观察器对已有 R 的 teacher forcing；RAGTruth 回答来自其他生成器。即使取得 full-model logp，它也是该观察器的条件概率，不是原生成器当时记录的采样概率。相关或干预结论先限于观察器处理已有回答的机制，不能冒充 GPT/Mistral/Llama2 的原始生成原因。
- Summary/Data2txt 的已知扩展是局部回答历史 attention，不能当作同范围的来源 QKV。
- 重放原始生成计算需遮蔽未来 K/V；若离线检测器使用完整回答，应明确它属于全文检测，并与文本基线给予相同上下文。

## 如何验证价值

先做无标签的关系候选许可和缓存合同检查，再看现有回答的分离观测；需要最终输出因果区分时才补采必要 forward。最后对原回答 token/span 的 AUROC/AP、定位、coverage、固定预算 FN/FP 和完整成本，与强直接文本核验及既有 R4/V3 比较。缓存边际分析成本与额外8B观察器的真实采集成本分别报告。

理论从可识别性开始：若一个观测在“改变数值所属主体”后保持不变，它不能区分词袋相同、固定回答支持关系相反的成对来源。这是对满足该不变性观测的有限论证，**不是未经检验就宣布 R4/V3 必然不变或必然无效**。
