# 当前主目标：检测已有回答中的幻觉

用户于 2026-11-03 再次纠正：需要的是幻觉检测效果，不能用验证器回答角色问题的正确率代替检测效果。本文件约束后续实验与换机续接；历史实验原始记录保留。

## 输入、输出与评价对象

- 输入：原始来源 S、实际可用的原问题/提示 Q，以及已经生成的待检测回答 R。未恢复的原问题保持缺失，不从 R 猜造。
- 输出：R 原有评价轴上的幻觉风险分数及明确的 coverage/unknown。保留原回答字节、原 token/发布标注单位与完整人口。
- 评价：判断风险分数能否区分 R 中发布标注的错误与非错误区域；检测器内部重新回答的问题不是主评价对象。
- 设定：无目标标签训练。方法、模块规则、参数、人口和全部分数先冻结，再读取目标真值评价。已暴露人口保持探索性质。

## 一次新方法实验必须交付什么

1. 实际产生原回答风险分数的完整方法和可运行入口；未实现的模块只登记为提案。
2. 与 R4/V3 兼容人口上的检测比较，记录模型、backend、观察预算差异，不能把不同仪器伪装为受控单变量比较。
3. 主结果为六个声明任务各自的 AUROC、AP、完整评价分母、coverage/unknown 与成本。阶段性面板结果标明范围，不能冒充全任务结果。
4. FN/FP、TP/召回等使用预先冻结的判定规则或已有告警预算；不能按目标标签选择阈值，也不能把 AUROC=1 解释为所有二元判定正确。
5. 模块消融直接检查原回答检测分数和完整检测指标。解释实际修复的 FN、引入的 FP、未改善的任务及来源差异；不因少量错例修复就宣布整体改进。

六任务各 AUROC ≥ 0.8 仍是目标，不是当前已实现的结果。新颖性、理论主张和顶会水准均需另外举证。

## 对辅助模块与支线的约束

QA、NLI、关系抽取等可以是内部观测，但必须说明如何在不读取目标真值的情况下变成 R 的检测证据，并直接接受上述检测评价。验证器答对、实体距离接近、注意力高、模型输出自洽，均不单独证明 R 有无幻觉。

H015/H016 已完成并关闭：工程仪器资格与已暴露 toy 的角色重建结果只保留作辅助记录。H016 的9/16、16/16、15/16、16/16不是自然数据幻觉检测准确率，不再用它们作为主线取得检测提升的证据；停止扩展独立的角色问答榜单，也不重复312个已封存观察。

新模块若只能改善内部问答、无法输出自然原回答的检测分数，停止向它追加模型实验，先补齐检测接口与适用性论证。不能为了让联合指派生效，强加自然数据不具备的双射前提。

## 续接顺序

先复用已有自然数据、原 token 缓存与 FN/FP 审计，读取 research-state 中已经关闭的失败和未知前提，不再重复描述已知现象。围绕一个未解决的错误成因提出一个无标签模块及必要对照；完成检测接口、完整人口和评价协议冻结后，才登记并运行新观察。

当前尚无经过六任务新全量检测评价的 H016 自然检测器，也没有另一个已获准启动的“新版角色问答”实验。另一台电脑以本文件、RESUME.md、事实/决策索引和 REMOTE_EXPERIMENT_HANDOFF.md 续接。
